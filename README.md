## Medical Image Segmentation
- Explored deep learning models for segmenting endoscopic tool images using the Kvasir-Instrument dataset.

- Evaluated architectures like DeepLabV3+, DUCK-Net, SwinV2 Transformer, and EfficientNet.

- Ran experiments on image resolution, data augmentation, training size, optimizers, and activation functions.

- Applied techniques like learning rate scheduling and early stopping to improve training.

- Assessed performance using metrics such as Dice Similarity Coefficient, IoU, Precision, and Recall. The project culminated in a comprehensive analysis of segmentation performance across multiple configurations

## Machine Learning and NLP
- A multi-part project applying machine learning and natural language processing techniques to real-world datasets.

- Classification: Predicted health risk levels using metrics like heart rate and cholesterol.

- Clustering: Analyzed urban mobility patterns to uncover commuting behaviors.

- Deep Learning Regression: Built a neural network to predict property prices based on housing features.

- Text Processing & Feature Representation: Cleaned and vectorized movie descriptions using TF and TF-IDF.

- Topic Modeling: Extracted themes from movie reviews using LDA and SVD.

- Recommendation System: Suggested similar movies using cosine similarity, excluding disliked titles. This project demonstrates a full pipeline from preprocessing to model evaluation and insight generation
